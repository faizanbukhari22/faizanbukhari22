## ◼ FEATURED PROJECTS

<!-- PROJECTS:START -->
> ### ▲ TestPilot
> **MCP-based demo connecting an AI/voice interface to a simulated Hardware-in-the-Loop (HIL) test bench, bridging automotive HiL test automation experience with agentic AI tooling.**
>
> ● FastMCP server exposes bench-sensor read and named-test tools (power rail, thermal, current draw) to an orchestrator client via the Model Context Protocol, with safe-by-default confirmation gating on all test-execution commands, deterministic pass/fail results persisted as local JSON test history, and an offline text mode requiring no API keys.
> ● Optional voice mode via Deepgram transcription and OpenRouter for natural-language tool selection.
> ● Includes automated unit tests for the simulated hardware bridge.
>
> **Stack:** `Python` `FastMCP` `Model Context Protocol` `Deepgram` `OpenRouter` `JSON-backed state simulator` `unittest`
> **Repo:** [github.com/faizanbukhari22/TestPilot](https://github.com/faizanbukhari22/TestPilot)

> ### ▲ scholarstack
> **Production-grade multi-agent pipeline that transforms YouTube lectures into structured study notes, Anki-compatible flashcards, and a hallucination audit report.**
>
> ● Five isolated layers: media ingestion (yt-dlp/FFmpeg), local ML transcription (faster-whisper, no cloud costs), parallel async Gemini agent orchestration, structured Pydantic verification with self-correction loop, and an MCP server exposing the full pipeline as seven callable tools.
> ● Deployed as a Gradio app on Hugging Face Spaces.
>
> **Stack:** `Python 3.11` `Gemini API` `faster-whisper` `FastMCP` `Pydantic` `asyncio` `Docker` `Docker Compose` `Gradio` `GitHub Actions CI` `yt-dlp` `FFmpeg`
> **Repo:** [github.com/faizanbukhari22/scholarstack](https://github.com/faizanbukhari22/scholarstack)

> ### ▲ ai-test-gen
> **Python CLI that uses Anthropic Claude (claude-sonnet-4-6) via LangChain-Anthropic to convert plain-language software requirements into Gherkin .feature files, structured test cases (happy path, edge case, security), coverage estimates, and JSON exports ready for Jira/TestRail integration.**
>
> ● End-to-end prototyping with agentic workflows and MCP integration.
> ● Built using Claude Code as the primary AI-assisted development environment.
> ● Additional projects in development.
>
> **Stack:** `Python 3.10+` `Anthropic Claude API` `LangChain-Anthropic` `LangGraph` `Claude Code` `Pydantic` `Click` `Rich` `PyTest`
> **Repo:** [github.com/faizanbukhari22/AI-Test-Case-Generator-Python-LLM-Agent](https://github.com/faizanbukhari22/AI-Test-Case-Generator-Python-LLM-Agent)
